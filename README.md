# Second Brain

Your work is spread across documents, messages and meetings. This Claude plugin brings it together so you can ask questions and find what you need.

## Get started

1. [Download the plugin ZIP](https://github.com/gilor123/second-brain/releases/download/v0.2.1/second-brain-0.2.1.zip). Keep it zipped.
2. In Claude, open **Customize → Plugins** and upload it.
3. Start a new Cowork task and type **“Set up my second brain.”**

Claude will help you choose a folder, add your documents and try your first question.

Then it sets up automatic updates from your connected Slack, Gmail, Zoom and Claude conversations, plus tasks to keep your Second Brain organized. It tests them before calling setup complete. If you need to approve access, it tells you what to click.

## Make it yours

Add more documents. Ask questions. Tell Claude what to collect or leave out. You can change or pause the automatic tasks in **Scheduled**.

You’ll need Claude with folder access. Connected apps and automatic updates depend on what your account supports; setup checks this for you. Your files stay in the folder you choose.
